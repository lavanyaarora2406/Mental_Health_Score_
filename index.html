    About

    A single-purpose prediction tool

    This interface sends a student's profile to a locally running FastAPI service, which passes it through a trained regression model and returns a single numeric score. Nothing is stored, and no request is sent anywhere beyond the local API.

    Model

    What the score means

    The score reflects patterns learned from prior student data — it is a statistical estimate, not a medical assessment. Use it as a starting point for reflection, not a conclusion.
